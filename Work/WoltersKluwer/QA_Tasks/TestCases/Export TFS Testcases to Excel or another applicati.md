## Export TFS Testcases to Excel or another application

This only works for an entire testplan, not for single testcases or test suites


- Open TFS ([http://devdavlin:8080/tfs/Alure/alure/](http://devdavlin:8080/tfs/Alure/alure/_testManagement?planId=16647&suiteId=16655&_a=tests))
- Select testrun to export
![a3f454824a62b28726e65b581f20f081.png](../.attachments/7d01009ba6e0432895451420a2298dec.png)

- Press the export button 
![c6c861e2699dc0e6b1dcf0a300534851.png](../.attachments/76b2e07f2417486c8e646761c280d73b.png)

- On the export screen, the checkboxes for the Test plan are not always necesary, but leave them checked so you will get all info related to the testcases
- Also make sure the radio button for "selected suite + childern" is selected
- All checkboxess for Test suite and test cases should be checked
![411acb1a20f9a2c87ac8fdc0ad0b6e81.png](../.attachments/46ddc71085a04e5daa6fc20620d974ee.png)

- Press Email or print button, whatever you want
- On Email you have to give an e-mail address to send the list to
- On Print you can select the tekst from the screen and copy/pase it to Excel for example or actualy print it
