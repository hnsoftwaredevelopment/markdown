Dit is een collectie met short keys, handig voor dagelijks gebruik. Let wel het is niet de bedoeling hier een verzameling neer te zetten van ALLE beschikbare short keys, want dan wordt de lijst onnodig lang door short keys die toch nooit door mij worden gebruikt.

| Short key          | Omschrijving                                   |
| :----------------- | ---------------------------------------------- |
| ⊞ + .              | Speciale tekens                                |
| ⊞ + A              | Snelle settings                                |
| ⊞ + `crtl` + ⇑ + B | Maak systeem weer wakker bij zwart scherm      |
| ⊞ + D              | Mini-/Maximaliseer alle windows                |
| ⊞ + E              | Open Windows verkenner                         |
| ⊞ + I              | Open het instellingen scherm                   |
| ⊞ + L              | Lock je computer                               |
| ⊞ + R              | Open Run dialog                                |
| ⊞ + V              | Klembord geschiedenis                          |
| ⊞ + `ctrl` + V     | Volume settings                                |
| ⊞ + X              | Windows system app (zelfde als: right click ⊞) |
