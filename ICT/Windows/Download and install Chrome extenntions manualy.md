# Download and install Chrome extenntions manualy
## First get the crx file
1. Goto the extentions page of the extention you want to install
2. Goto [crxextractor](http://crxextractor.com/)
3. Add the URL in the textfield and download
4. Get the downloaded CRX file and drop it on the same crxextractor webpage a zipfile is created and downloaded
5. Unzip the zip downloaded zipfile
6. Goto [Extensions page](chrome://extensions/)
7. Turn on Developers mode (if not already on)
8. Click the Load unpacked extension button and select the unzipped folder for your extension to install it.
