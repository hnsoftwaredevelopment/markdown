## Schrijfafspraak

Per component gebruiken we zoveel mogelijk dezelfde structuur:

1. Wat is het?
2. Wanneer gebruik je het?
3. Basisvoorbeeld
4. Belangrijkste properties
5. Uitgebreid besproken properties
6. Wat kan er binnen dit component?
7. Veelgemaakte fouten
8. Praktijkvoorbeeld

Veelgebruikte properties mogen uitgebreider worden beschreven.
Minder belangrijke properties kunnen compact in een tabel blijven staan.
