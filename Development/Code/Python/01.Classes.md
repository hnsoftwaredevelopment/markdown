## Add method

We now want to print the full name of the employee using the format First Last separated with a space.

We have to add this print line to the code somewhere after line 14
`print('{} {}'.format(emp_1.first, emp_1.last))`

But this if you have to print all full names everywhere like this it is also a lot of extra code that makes the code not better readable, it is better to create a method to the class to help printing the formatted printing of the full name

## 

```python
# Python class explanation


class Employee
	def __init__(self, first, last, pay):
        self.first = first
        self.last= last
        self.pay = pay
        self.email = first + '.' + last + '@company.com'
     
    def fullname(self):
        return '{} {}'.format(self.first, self.last)

# Create 2 employees
emp_1 = Employee('Jan', 'Versteeg', 50000)
emp_2 = Employee('Peter', 'Doesburg', 53000)

# Instead of using print('{} {}'.format(emp_1.first, emp_1.last)) whe can use next print statement printing the fullname formatted correctly
print(emp_1.fullname())

# the output shows the fullname of employee 1
>>> Jan Versteeg
```



It is important to use

`print(emp_1.fullname())`

Of you forget the parentages at the end and do

`print(emp_1.fullname)`

The output will be

`>>> <bound method Employee.fullname of <__main__.Employee object at 0x101977b00>>`

So this means simply the syntax of the print statement is not correct and you called `fullname` instead of `fullname()`

Another error is that you forget Self in line 11 `def fullname():`

if you would run the code you would get an error like:

`>>> TypeError: fullname() takes 0 positional arguments but 1 was given`

So this means 'Hey fool you forgot the self argument in the definition of the method'
