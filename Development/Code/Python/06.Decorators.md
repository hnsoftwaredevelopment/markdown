# Decorators - Getters, Setters and Deleters

We start with a stript example and run it to check the outcome

```python
class Employee:
    def __init__(self, first, last):
        self.first = first
        self.last = last
        self.email = first + '.' + last + '@company.com'
        
    def fullname(self):
        return '{} {}'.format(self.first, self.last)


emp_1 = Employee('Jan', 'Versteeg')
emp_2 = Employee('Peter', 'Doesburg')

print(emp_1.first)
print(emp_1.email)
print(emp_1.fullname())
>>> Jan
>>> Jan.Versteeg@company.com
>>> Jan Versteeg
```



Now we change the code so the firstname is changed. After rerun you'll see that the email address is not changed, only the first name and the fullname. Because the firstname is addresed directly and the fullname is always using the current first and last name

But creating an email method just as the fullname method will not do the trick, althoug the email address will be updated corrrectly we have to fix the code where the email is used, because () have to be added to the code

For example `print(emp_1.email)` has to be changed into `print(emp_1.email()).`

To prevent this we have to change this method into a property by adding `@property` above the method. This way you don't have to change the rest of the code becuause the created method will be treated as it was a property

```python
class Employee:
    def __init__(self, first, last):
        self.first = first
        self.last = last
    
    @property
    def email(self):
        return '{}.{}@company.com'.format(self.first, self.last)    
    
    def fullname(self):
        return '{} {}'.format(self.first, self.last)


emp_1 = Employee('Jan', 'Versteeg')
emp_2 = Employee('Peter', 'Doesburg')

emp_1.first = 'Jim'

print(emp_1.first)
print(emp_1.email)
print(emp_1.fullname())
>>> Jim
>>> Jim.Versteeg@company.com
>>> Jim Versteeg
```

Other functionality you might want is that you enter the full name of an employee end its split up into a first- and last name, and also change the e-mail address.

We cannot avoid to change code in the rest of the application (remove parantheses after the method name)

First we make a property of the fullname method (line 10)

Then we have to create a setter, using the name of the property we want to use.

We want to use fullname so we create a setter for fullname (line 14)

now we define a decorator for the same fullname (line 15-18)

last don't forget the parentheses after fullname in line 28 because fullname is a property now

```python
class Employee:
    def __init__(self, first, last):
        self.first = first
        self.last = last
    
    @property
    def email(self):
        return '{}.{}@company.com'.format(self.first, self.last)    
    
    @property
    def fullname(self):
        return '{} {}'.format(self.first, self.last)
	
    @fullname.setter
    def fullname(self, name):
        first, last = name.split(' ')
        self.first = first
        self.last = last

        
emp_1 = Employee('Jan', 'Versteeg')
emp_2 = Employee('Peter', 'Doesburg')

emp_1.fullname = 'Gertrude Aardenburgh'

print(emp_1.first)
print(emp_1.email)
print(emp_1.fullname
>>> Gertrude
>>> Gertrude.Aardenburgh@company.com
>>> Gertrude Aardenburgh
```

Same way we can create a deleter, so we can delete a employee using its fullname

```python
class Employee:
    def __init__(self, first, last):
        self.first = first
        self.last = last
    
    @property
    def email(self):
        return '{}.{}@company.com'.format(self.first, self.last)    
    
    @property
    def fullname(self):
        return '{} {}'.format(self.first, self.last)
	
    @fullname.setter
    def fullname(self, name):
        first, last = name.split(' ')
        self.first = first
        self.last = last

    @fullname.deleter
    def fullname(self):
        print('Delete Name!')
        self.first = None
        self.last = None

        
emp_1 = Employee('Jan', 'Versteeg')
emp_2 = Employee('Peter', 'Doesburg')

emp_1.fullname = 'Gertrude Aardenburgh'

print(emp_1.first)
print(emp_1.email)
print(emp_1.fullname)

del emp_1.fullname
print(emp_1.fullname)      
      
>>> Gertrude
>>> Gertrude.Aardenburgh@company.com
>>> Gertrude Aardenburgh
>>> Delete Name!
>>> None None
```
