# Special methods

Inside classes you can use special methods to improve or clarify the outcome of the method.

Special methods are always surrounded by double underscores (so __init__ is also a special method) **D**ouble **under**scores are also called Dunder.

So Special Methods = Magic(al) Methods = Dunder Methods

And if someone says dunder init he/she means init surrounded by double underscore so: 
`__init__`

For example Python itself acts different when adding two integers or two strings together,

`print(1 + 2)`
`>>> 3`

`print('a' + 'b')`
`>>> ab`

Same when, in our previous coding examples, u use the statement:

`print(emp_1)`

it gives: `<__main__.Employee object at 0x011b2b0f0>`

not a very useful outcome, so it would be nice that the outcome would be more clear, to do so we use special (or magic) methods

the repr method is used for technical representation of an object and can be used for logging or debugging (used for other developers)

the str method is used for readable representation of an object and can be used for displaying information to the end user

Without special methods printing the empl_1 results in


Now we create an example that will add the pay of two employees together wen we print the calculation. So adding the dunder add function we tell the application how to act when we want to add employees to another. Otherwise it will throw an error because Python doesn't know how to add two employees together.

```python
# Python class explanation


class Employee:

    num_of_emps = 0
    raise_amount = 1.04

    def __init__(self, first, last, pay):
        self.first = first
        self.last = last
        self.pay = pay
        self.email = first + '.' + last + '@company.com'

        Employee.num_of_emps += 1

    def fullname(self):
        return '{} {}'.format(self.first, self.last)

    def apply_raise(self):
        self.pay = int(self.pay * 1.04)

    def __repr__(self):
        return "Employee('{}', '{}', '{}')".format(self.first, self.last, self.pay)
    
    def __str__(self):
        return "Employee('{}' - '{}')".format(self.fullname(), self.email)
    
    def __add_(self, other):
        return self.pay + other.pay
         
emp_1 = Employee('Jan', 'Versteeg', 50000)
emp_2 = Employee('Peter', 'Doesburg', 53000)

print(emp_1 + emp_2)
```
