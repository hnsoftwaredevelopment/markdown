## Use class variables

class variables are used among instances of a class



We are creating a new method apply_raise that uses the variable pay

```python
# Python class explanation


class Employee
	def __init__(self, first, last, pay):
        self.first = first
        self.last= last
        self.pay = pay
        self.email = first + '.' + last + '@company.com'
        
    def fullname(self):
        return '{} {}'.format(self.first, self.last)
    
    def apply_raise(self)
        self.pay = int(self.pay * 1.04)

# Create 2 employees
emp_1 = Employee('Jan', 'Versteeg', 50000)
emp_2 = Employee('Peter', 'Doesburg', 53000)

#First print the payment as set by default
print(emp_1.pay)
>>> 50000

#call the apply_rayse method so the pay will be raised by 4%
emp_1.apply_raise()
print(emp_1.pay)
>>> 52000


```

Problem in this example is that the raise is a fixed amount, just make it variable

We can doo that creating a class variable (line 6) and use it as described in line 18 or 19

```python
# Python class explanation

print(emp_1.rayse_amount)

```

If the used class variable is not in the function, it searches it a level higer until it finds it.
So there is no raise_amount defined in the def __init__ class itself,(emp_1.raise_amount, there is no raise_amount in the function that creates the employee) so Python checks one level higher and there it finds the class variable.

But it also possible that not the default raise amount is changed but an individual raise amount. Every Employee in the company gets a raise of 4% except employee1 she gets a raise of 5%

Therefore we should use self.raise_amount in line 20, otherwise it would always refer to the class variable

```python
# Python class explanation


class Employee

	raise_amount = 1.04
    
	def __init__(self, first, last, pay):
        self.first = first
        self.last= last
        self.pay = pay
        self.email = first + '.' + last + '@company.com'
        
    def fullname(self):
        return '{} {}'.format(self.first, self.last)
    
    def apply_raise(self)
        #self.pay = int(self.pay * Employee.raise_amount)
        #now use self to be able to raise individualy
        self.pay = int(self.pay * self.raise_amount)

# Create 2 employees
emp_1 = Employee('Jan', 'Versteeg', 50000)
emp_2 = Employee('Peter', 'Doesburg', 53000)

#change the raise ammount
emp_1.raise_amount = 1.05

#Now print the payment as changed in the previous codeline
print(emp_1.rayse_amount)
>>> 1.05

print(emp_2.rayse_amount)
>>> 1.04

print(Employee.raise_amount)
>>> 1.04

#Check the namespace of emp_1 and see che raise_amount is now part of the namespace of emp_1
print(emp_1.__dict__)
>>> {'raise_amount': 1.05, 'first': 'Jan', 'pay': 50000, 'email': 'Jan.Versteeg@company.com', 'last': 'Versteeg'}

#Emp_2 did not get the extra raise so its namespace will get the set class variable, the raise_amount is not part of the namespace of emp_2
print(emp_2.__dict__)
>>> {'first': 'Jan', 'pay': 50000, 'email': 'Jan.Versteeg@company.com', 'last': 'Versteeg'}
```

Use a counter as class variable, as example we count the number of employees

```python
# Python class explanation


class Employee

	num_of_emps = 0
    raise_amount = 1.04
    
	def __init__(self, first, last, pay):
        self.first = first
        self.last= last
        self.pay = pay
        self.email = first + '.' + last + '@company.com'
        
        Employee.num_of_emps += 1
        
    def fullname(self):
        return '{} {}'.format(self.first, self.last)
    
    def apply_raise(self)
        #self.pay = int(self.pay * Employee.raise_amount)
        #now use self to be able to raise individualy
        self.pay = int(self.pay * self.raise_amount)

#How many employees are in the company now?
print(Employee.num_of_emps)
>>> 0
        
# Create 2 employees
emp_1 = Employee('Jan', 'Versteeg', 50000)
emp_2 = Employee('Peter', 'Doesburg', 53000)

#Check again how many employees are in the company
print(Employee.num_of_emps)
>>> 2

```
