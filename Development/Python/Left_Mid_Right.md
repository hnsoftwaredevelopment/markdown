Left_Mid_Right

# Left, Mid, Right

## LEFT

```python
# Syntax string[:amount]
print('Hello nice world'[:5])

>>>>> Hello
```



 

## MID

```python
# Syntax string[offset:offset+amount]
print('Hello nice world'[6:10])

>>>>> nice
```



 

## RIGHT

```python
# Syntax string[-amount:]
print('Hello nice world'[-5:])

>>>>> world
```
