# Usage of classmethods and staticmethods

What are classmethods, when do we use them and what is the difference with a staticmathod



self is an example of a regularmethod, so it takes the class as the first argument, how can we change self so it won't take the class.

We create a decorator to do so in line 23

cls in line 24 means class, but you can't use the word class instead therefore you use cls instead. This line now tells us we use raise_amt instead of the class (self) as first argument

```python
# Python class explanation


class Employee

	num_of_emps = 0
    raise_amount = 1.04
    
	def __init__(self, first, last, pay):
        self.first = first
        self.last= last
        self.pay = pay
        self.email = first + '.' + last + '@company.com'
        
        Employee.num_of_emps += 1
        
    def fullname(self):
        return '{} {}'.format(self.first, self.last)
    
    def apply_raise(self)
        self.pay = int(self.pay * 1.04)

    @classmethod
    def set_raise_amt(cls, amount):
        cls.raise_amt = amount
    
# Create 2 employees
emp_1 = Employee('Jan', 'Versteeg', 50000)
emp_2 = Employee('Peter', 'Doesburg', 53000)

#Print the deault rates
print(Employee.raise_amt)
print(emp_1.raise_amt)
print(emp_2.raise_amt)
```
