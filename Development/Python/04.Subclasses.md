# Inheritance - Creating subclasses

When you want to create a new class, and that class will need the output from another class. Don't Copy-Paste the code of the existing class into the new class. But create a new class inheriting the output of the excising class.

Look at line 39, a new class Developer is made and between parenthesis the name of the existing class is mentioned
