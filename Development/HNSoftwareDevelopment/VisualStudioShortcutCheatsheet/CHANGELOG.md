# Changelog

## 1.0.1

No changes to the extension itself.

- The images on the Marketplace page load from GitHub.
- The package no longer contains debug symbols.

## 1.0.0

First release: a cheat sheet of every keyboard shortcut in your own Visual Studio 2026.

- **The window** (View > Other Windows > Shortcut Cheatsheet) shows all shortcuts with the keys drawn as keys, grouped by where they work, by category, by extension, or as one list by keys. Search by name, command or keys (`ctrl+e,v`).
- **Which extension adds a shortcut**, read from the compiled command tables of the installed extensions without loading them.
- **Your own shortcuts** are marked, and can be listed on their own.
- **Shortcuts that were not applied**: default shortcuts of an extension that Visual Studio skipped because the keys were taken, with the command that has them.
- **Export** to PDF, PNG, HTML, Markdown, CSV, JSON and XML, following the search, filters and grouping of the window.
- **Settings** in both Options dialogs: language, default grouping, paper size, colors and columns for PDF and PNG.
- **15 languages**: English, Chinese (simplified and traditional), Czech, Dutch, French, German, Italian, Japanese, Korean, Polish, Portuguese (Brazil), Russian, Spanish and Turkish.
