## If you are inside "", (), <>, []
### CTRL+Shift+Enter
While typing if you for example inside "" then you can use Shift+CTRL+Enter To exit the quotes and enter a semicolumn at the end.

### TAB
Also with TAB ou can exit quotes or brackets, and jump after them in the sam line, no semicolumn is added when using the TAB key

## Smart Completion insteasd of COde completion
When entering code Code completeion is working, but you can also use Smart Completion using CTRL+Shift+Space. Only relevant options are shown then, or filled in if there is only 1 option

## Use option from code completion to replace youre currect selection
If the Code completion pops up it is better to use TAB insted of mouseclick or Space, because with Tab it also replaces the part that is not valid anymore.
